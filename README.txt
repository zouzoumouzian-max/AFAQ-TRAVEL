AFAQ TRAVEL — ملفات نسخة قابلة للتثبيت كتطبيق PWA

الملفات:
- index.html: الموقع مع واجهة ترحيبية.
- manifest.json: اسم التطبيق وأيقوناته وإعدادات التثبيت.
- sw.js: تخزين ملفات الواجهة الأساسية مؤقتاً.
- afaq-icon-192.png و afaq-icon-512.png: أيقونات التطبيق.

للنشر على GitHub Pages:
1. ارفعي محتويات هذا المجلد إلى جذر المستودع (Root)، وليس المجلد المضغوط نفسه.
2. يجب أن يكون index.html في الجذر مباشرة.
3. فعّلي GitHub Pages من Settings > Pages واختاري Deploy from a branch ثم main و /(root).
4. افتحي رابط الموقع عبر HTTPS ثم من قائمة المتصفح اختاري Add to Home screen / Installer.

ملاحظات:
- الصور الخارجية والخطوط تحتاج اتصالاً بالإنترنت.
- نموذج طلب الرحلة في هذه النسخة تجريبي ويُحفظ محلياً على الجهاز فقط، وليس حجزاً حقيقياً ولا يرسل الطلب إلى وكالة.
- بيانات الهاتف والبريد الموجودة في الصفحة أمثلة تجريبية ويجب استبدالها قبل عرض الموقع على عميل حقيقي.
